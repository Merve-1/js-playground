# JavaScript Student Guide & Code Reference

A practical, beginner-friendly guide to learning JavaScript through examples, exercises, and hands-on projects.

This repository is designed to help students understand core JavaScript concepts, practice problem-solving, and apply what they learn by building interactive web applications. It serves as both a learning resource and a code reference that students can revisit whenever they need help understanding a concept or implementing a feature.

Rather than focusing only on theory, this guide emphasizes learning by doing, starting with JavaScript fundamentals and gradually progressing toward complete projects.

## 🎯 Learning Objectives

By working through this repository, you will learn how to:

- Understand JavaScript syntax, variables, data types, operators, and conditions.
- Use loops to solve problems and automate repetitive tasks.
- Work with arrays, functions, and objects to organize and process data.
- Build interactive web pages using events and DOM manipulation.
- Display dynamic content and create simple applications.
- Store and retrieve data using Local Storage.
- Fetch data from external APIs and work with asynchronous requests.
- Build practical projects such as a Student Management System and a mini e-commerce store.
- Turn UI designs into functional web applications.
- Develop problem-solving skills and write more organized, reusable code.

## 🚀 Getting Started

### Prerequisites

Before starting, you should have:

- Basic familiarity with using a computer and a web browser.
- A code editor, such as Visual Studio Code.
- A modern web browser.
- Curiosity and a willingness to practice.

No advanced JavaScript knowledge is required. The topics are organized to help you progress from fundamentals to practical applications.

### Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/Merve-1/js-playground
```

Navigate into the project folder:

```bash
cd js=playground
```

Open the folder in your preferred code editor.

If a lesson contains a standalone HTML file, you can usually open it in your browser. For projects that use APIs or require a local web server, follow the instructions provided in the relevant lesson.
