# Login Validation

## Goal
Keep asking the user for their username and password until the correct credentials are entered.

## Requirements
- Store a demo username and password.
- Use a loop to repeat the login prompt.
- Use conditions to validate the credentials.
- Display a success message when the login is correct.

## Bonus Challenge
- Allow only three login attempts.
- If the user enters incorrect credentials three times, display an access-denied message.
