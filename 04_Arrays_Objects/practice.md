# **Practice 1: Calculate Average Grades**

Create a function called `calculateAverage(students)` that calculates and returns the average grade of all students.

### **Requirements**

- Use a loop.
- Calculate the total grades.
- Divide the total by the number of students.
- Return the average.

Expected output:

```
Average: 80.5
```
