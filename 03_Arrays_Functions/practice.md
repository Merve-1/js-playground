## Shopping Cart Total

Goal: Create a function that receives an array of product prices and returns the total price.

Requirements:

1. Create an array containing different product prices.
2. Create a function called `calculateTotal()`.
3. Pass the prices array as an argument.
4. Use a loop to calculate the total.
5. Return the total using `return`.
6. Print the result outside the function.

Expected output:

```
Total price: 850
```

Bonus Challenge:

- Calculate the average price.
- Find the most expensive product.
- Apply a 10% discount if the total exceeds 500.
